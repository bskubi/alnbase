=== 1. Soft clip: does it shift the position axis? ===
edit at read offset 2 (0-based) = base 3 of the read as sequenced
reference position of that base: 1003 (1-based)
in clipped.bam it is the FIRST aligned base

           -mbp 0   1   2   3   4
endtoend   AG    AG    AG    DROP  DROP  
clipped    AG    AG    AG    DROP  DROP  
The edit is read base 3 in both files. Identical thresholds => the clip does
not shift the axis; the filter counts from the read's own first base.

=== 2. Reverse strand: does the filter flip? ===
ref 1003 = SEQ index 2 ; ref 1038 = SEQ index 37
FLAG 16: ref1038 is read base 3 as sequenced, ref1003 is read base 38

       ref1003 (SEQ idx 2)    ref1038 (SEQ idx 37)
fwd    -mbp 0 -> AT              AT
fwd    -mbp 3 -> DROP            AT
rev    -mbp 0 -> AT              AT
rev    -mbp 3 -> DROP            AT
For the FLAG-16 file, SEQ index 37 is read base 3 AS SEQUENCED and SEQ index 2
is read base 38. -mbp 3 drops index 2 and keeps index 37 in both files, so it
counts from SEQ position 0 and trims the wrong end of every reverse read.

=== 3. -mbp and -Mbp are not symmetric ===
         3rd base from that end
-mbp 2   AT
-mbp 3   DROP
-Mbp 3   AT
-Mbp 4   DROP
-mbp N ignores the first N bases; -Mbp N ignores only the last N-1.
