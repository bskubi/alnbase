== The four probes, as the rule calls them
   pair  flag  sequenced from  informs about  rule says
   CTOB  99    CTOB            -              +   <- wrong
   CTOB  147   OB              -              +   <- wrong
   CTOT  83    CTOT            +              -   <- wrong
   CTOT  163   OT              +              -   <- wrong
   OB    83    OB              -              -
   OB    163   CTOB            -              -
   OT    99    OT              +              +
   OT    147   CTOT            +              +
   conversion strand wrong: 4 of 8

   CTOT and CTOB records are not the problem: read 2 of every ordinary fragment is one,
   and asTair gets those right. 99 and 147 together are 'an FR pair whose read 1 is
   forward', which is a top-strand fragment and both of its mates; 83 and 163 are the
   same for a bottom-strand fragment. What breaks is a pair whose READ 1 came from the
   copy strand, so that the pair's orientation is inverted relative to its fragment's
   strand -- the CTOT and CTOB pairs above. A directional library never produces one,
   and asTair is directional-only by design (--library directional|reverse; the docs
   call non-directional 'under development'). This measures that documented limit.
   What TAPS changes is only that nothing catches it earlier: the reference is not
   converted, so bwa maps such a pair as happily as any other.
