== compression and line endings give byte-identical indexes
gz.aref identical to plain.aref
bgz.aref identical to plain.aref
crlf.aref identical to plain.aref
== old-Mac CR-only line endings: the file is ONE line; accepted silently
   (comment lines removed first; otherwise the whole file is one ';' comment)
$ alnbase index cr.fa cr.aref
(exit 0)
$ alnbase info cr.aref
cr.aref
  format version  3
  contigs         1
  total bases     0
  file size       76 bytes

contigs
  chr1             0  d41d8cd98f00b204e9800998ecf8427e
(exit 0)
== errors
$ alnbase index before.fa before.aref
Error: sequence data before the first '>' header
(exit 1)
-- index writes OUT.partial and renames it only on success, so nothing is left behind:
cannot access 'before.aref': No such file or directory
cannot access 'before.aref.partial': No such file or directory
-- and a failed run over an existing index leaves that index intact:
$ alnbase index before.fa existing.aref
Error: sequence data before the first '>' header
(exit 1)
existing.aref unchanged
$ alnbase index noname.fa noname.aref
Error: FASTA record with an empty name
(exit 1)
$ alnbase index spacename.fa spacename.aref
Error: FASTA record with an empty name
(exit 1)

(exit 0)
$ alnbase info latin1.aref

(exit 1)
